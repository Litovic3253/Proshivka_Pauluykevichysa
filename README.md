# Прошивки Паулюкевичуса

Программа для Windows: считывает прошивку с Arduino (Uno / Nano / Pro Mini, ATmega328P) и
ESP32 / ESP32-S2 / ESP32-S3 / ESP32-C3 по USB, сохраняет её в библиотеку, показывает, что
внутри, и заливает на другую плату. Интернет не нужен, прошивки хранятся в папке «Прошивки»
рядом с программой.

- Выбор COM-порта по имени: «COM5 · CH340 · USB 1A86:7523».
- Чтение всей flash, только приложения или отдельного раздела (ESP32); скачивание `.bin` / `.hex`.
- Анализ: паспорт приложения ESP32, таблица разделов, текстовые строки, просмотр HEX.
- Заливка с проверкой совместимости и сверкой записанного.
- Оформление и темы — как в «Студии Паулюкевичуса».

Исходный код из платы получить нельзя — только скомпилированную прошивку.

## Где что лежит

- [`firmware-site/`](firmware-site/) — исходники программы (Electron + React + TypeScript), сборка и проверка —

- [`docs/superpowers/specs/`](docs/superpowers/specs/) — спецификации, [`docs/superpowers/plans/`](docs/superpowers/plans/) — планы реализации.

## Сборка

```bash
cd firmware-site
npm install
npm test
```

`firmware-site\build_exe.bat` собирает переносной `Прошивки Паулюкевичуса.exe` (нужен Node 20.18+).

Чтение и заливка на настоящих платах проверяются вручную по чек-листу в `firmware-site/README.md`:
автотесты работают на эмуляторе загрузчика Arduino и на эталонных прошивках ESP-IDF.
