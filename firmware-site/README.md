# Прошивки Паулюкевичуса

Программа для чтения, сохранения и заливки прошивок Arduino (Uno / Nano / Pro Mini, ATmega328P)
и ESP32 / ESP32-S2 / ESP32-S3 / ESP32-C3. Программа для Windows: интернет не нужен,
прошивки хранятся в папке «Прошивки» рядом с программой.

## Программа

Готовая программа — `Прошивки Паулюкевичуса.exe` в папке проекта (на уровень выше `firmware-site`).
Один переносной файл, как у Студии: рядом с ним появляется папка «Прошивки» с прошивками.

- `build_exe.bat` — пересобрать `.exe` (кладёт его в папку проекта и в `dist-app\`).
- `npm run app` — собрать интерфейс и открыть программу при разработке.
- `npm run smoke` — дымовой прогон: скриншоты заставки и всех экранов во `%TEMP%\pauluk-smoke`.

Сборка требует Node 20.18+: Electron 39 и electron-builder 25 (более новые версии просят Node 22).
При первой сборке electron-builder скачивает набор `winCodeSign`; если Windows не даёт создать
символические ссылки (нет режима разработчика), распакованную папку нужно один раз переименовать
в `%LOCALAPPDATA%\electron-builder\Cache\winCodeSign\winCodeSign-2.6.0`.

## Проверка на железе

1. Arduino Nano/Uno: «Выбрать COM-порт» → зелёная точка «ATmega328P» → «Считать» → «Сохранить .hex».
2. Экран «Заливка»: залить эту прошивку на вторую такую же плату → «Готово» → плата работает так же.
3. Считать вторую плату и сравнить SHA-256 с первой (совпадёт, если загрузчики одинаковые).
4. ESP32: «Вся flash» (4 МБ — 1–5 минут) → залить на вторую плату → работает, настройки Wi-Fi сохранились.
5. ESP32: «Только приложение» → залить на плату с той же таблицей разделов.
6. Выдернуть кабель во время чтения → «Кабель отключён», программа не зависла.
7. Открыть монитор порта в Arduino IDE и нажать «Выбрать COM-порт» → «Порт занят другой программой».

## Разработка

```bash
npm test        # юнит-тесты (эмулятор загрузчика Arduino, поддельный esptool, фикстуры ESP-IDF)
npm run build   # сборка
```

Эталонные прошивки для тестов лежат в `tests/fixtures/` и собираются PlatformIO из `tools/fixtures/`:

- `avr-blink` — `pio run -d tools/fixtures/avr-blink`, затем скопировать `.pio/build/uno/firmware.hex`
  в `tests/fixtures/avr-blink.hex`.
- `esp32-hello` — ESP-IDF не собирает проекты в путях с пробелами («Рабочий стол»), поэтому папку
  нужно скопировать в путь без пробелов, собрать там `pio run` и скопировать `bootloader.bin`,
  `partitions.bin`, `firmware.bin` в `tests/fixtures/esp32-*.bin`.
- `make_otadata.py` — пересоздаёт `tests/fixtures/esp32-otadata-slot1.bin`.
